# ITDO 職務能力開発フレームワーク

職種を問わず必要な職務能力の体系、診断設計、セルフワーク、AI学習コーチを管理する公開リポジトリです。

## 初期登録の状態

初期登録用の `main` を作成しました。能力体系とW-A1・W-B1の教材は `chore/bootstrap-public-framework` からのPRで登録・レビューします。教材は開発中の試作であり、Gemini実機の受入確認や採用適性検査としての妥当性検証を完了したものではありません。

## 公開と非公開の境界

公開するのは能力定義、架空の教材、練習用の解説、指導仕様、未記入の記録テンプレートです。社員・応募者の氏名、回答、会話履歴、評価、採否、顧客情報、認証情報、採用本番の未公開問題は登録しません。個人への適用結果は権限を限定したGoogle Workspaceで管理します。

AIは学習支援を担当し、人事評価や採否を自動確定しません。Geminiなどの実行基盤と教材の正本を分離します。
