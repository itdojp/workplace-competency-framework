# 開発計画

開始日は未設定。担当者と職務要求を承認してから日付を設定します。既存の能力辞書と制作順序を維持し、9領域36能力と36教材の完成を混同しません。

| 段階 | 作業 | 担当役割 | 完了条件 |
|---|---|---|---|
| 初期登録 | 辞書・設計台帳・W-A1/W-B1・公開方針を移管 | 保守担当・公開確認者 | 静的確認とPRレビュー |
| 第1週 | 職務例・要求水準・利用目的・共有範囲 | 制度責任者・技術/総務の代表 | 利用条件を承認 |
| 第2～3週 | 第1期12能力の診断と練習を制作 | 教材担当・評価者 | 原資料・設問・支援・別課題が揃う |
| 第4週 | Gemini実機受入と4～6名程度の試行 | 確認担当・試行者 | 動作・負担・採点差を記録 |
| 第5～6週 | 1人1～2能力の練習 | 本人・確認担当 | 初回答・修正・転移を記録 |
| 第7週 | 別フォームで再評価 | 評価者 | 暗記ではない適用を確認 |
| 第8週 | 実務に近い別場面と利用可否の判断 | 制度責任者 | 適用範囲と残課題を承認 |
| 後続 | 残24能力、職務別課題、採用専用版 | 各職務の担当 | 職務との対応と妥当性を確認 |

第1期はA1/A3/A4/B1/C1/C2/C3/D1/E2/H1/H2/I4。A2など第2期にある前提能力が不足する人には事前の支援を付け、制作順序を学習者への禁止条件にしません。

先行作業はW-A1とW-B1の実機受入です。Geminiでまだ実行していないため、動作適合も学習効果も未確認です。小規模試行は操作性・明瞭さ・評価者間の差を確認する段階で、採用後の成果予測の検証ではありません。

後続の技術作業：数式付きGoogle用テンプレートの公開版移管、教材から開始文を生成する処理、静的CI、Release、Gems/Skillsアダプター。プログラムのライセンスと権限を決めてから実装します。自動人事評価・自動採否は対象外です。
