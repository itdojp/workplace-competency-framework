# ADR-0001：教材をAI製品の機能から分離する

状態：採用。決定日：2026-09-24。

能力体系、原資料、設問、指導仕様、記録形式を正本として保持し、特定のGems/Skillsの存続を前提にしません。初期版の実行方式は、会社アカウントで許可されたGemini通常チャットへの全文貼付けです。試行を終えてから社員向けの操作簡略化を検討します。

Gems/Skillsの提供終了日、移行日、会社アカウント対応について、本初期登録では最新性を再調査していません。過去の試作に含まれた製品継続性の調査記録は公開移管しません。未公開実装に関する報道を確定した仕様として扱わず、管理者が実施時点の公式資料と会社画面を確認します。

Gems、Workspace Studio Skills、Agent Skills等への対応はアダプターとして追加し、会社契約、日本語、共有、更新、権限、停止、記録を検証します。ファイル名をSKILL.mdへ変えるだけで利用可能としません。プロンプトは指示であり技術的アクセス制御ではありません。

影響：初期の貼付け操作が必要です。一方で、AI製品のUIや契約が変わっても能力体系と固定課題を保持できます。実行基盤を変えた場合はtests/coach-behavior/acceptance.mdを再実施します。
