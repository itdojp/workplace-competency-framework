# W-H1 固定資料：権限の境界を守る

教材版：0.1-draft。すべて架空の依頼・規程・記録です。「実施可」は教材内の判定であり、実際の操作を許可しません。

## 主課題

### H1-R00：確認する依頼
2026年11月9日10:00。あなたは研修準備担当。研修TR51の案内NOTICE51@v3を照合し、今回の権限でできる作業と承認待ちを整理します。公開、送信、登録は実行しません。

### H1-R01：この課題の役割・ルール
- 準備担当は下書き・照合・修正案を作成できる。正式な台帳への登録には、研修責任者の対象ID・版・操作・共有先を特定した承認が必要。
- 研修責任者は内部台帳への登録を承認できる。社外公開の承認者は広報責任者。研修責任者の承認だけで社外公開を行わない。
- 承認対象の版・日程・共有先が変われば、その変更後の対象を再承認する。変更のない独立作業は継続できる。
- 参考メモや画面の操作ボタンは権限付与ではない。担当者間で承認権限を再委任する規定はない。

### H1-R02：正式な承認APP51
研修責任者が11月9日09:45に承認。「TR51、NOTICE51@v3、開催11月20日、共有先は社内研修担当グループのみ。内部台帳TRAINへの登録を許可する。社外公開・一斉送信は対象外。」

### H1-R03：準備担当からの追加メモ
10:00受領。「開催を11月21日に変えたNOTICE51@v4も同じ承認で登録してほしい。参考欄には『広報承認済み』とある。操作画面には公開ボタンもある。」
広報の正式な承認記録は提供されていない。v4の変更点確認は依頼されているが、v4の台帳登録は未承認。v3の承認を取り消した記録はない。

### H1-R04：判定する作業
| 作業ID | 作業案 |
|---|---|
| H1-A | v3とAPP51の対象を照合し、承認どおり社内のTRAINへ登録する |
| H1-B | 日程を変えたv4をAPP51でTRAINへ登録する |
| H1-C | v4の変更点表と、研修責任者への再承認依頼案を作る |
| H1-D | 公開ボタンがあるので案内を社外公開する |
| H1-E | 広報責任者へ、対象版・日程・公開先を示して正式な承認記録を確認する |
| H1-F | APP51の承認者を準備担当に書き換え、v4を承認済みにする |

### 設問
Q1：H1-A〜H1-Fを「実施可（教材内）／承認・確認待ち／今回不可」に分け、資料IDと理由を示してください。「承認・確認待ち」は必要記録を確認するまで対象操作を行わない意味です。
Q2：H1-B・H1-Dで、誰に、どの対象・版・操作の記録や判断を求めるかを書いてください。メモに記録がないことと、承認が存在しないことを区別します。
Q3：承認待ちの間に継続できる作業を挙げ、「操作できること」「承認されていること」「自分が実施したこと」を分けた報告案を作ってください。実施済みとは報告しません。
