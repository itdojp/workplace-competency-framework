# W-H1：権限の境界を守る

教材版：0.1-draft。固定教材・開始文を制作した育成試作です。Gemini実機、人間評価者の確認、学習効果は未検証です。実際の社内規程・複雑な契約解釈や法的判断は測りません。

## 参照と実行
[固定資料](materials.md)、[全文内包の開始文](start.txt)、[人間の確認ガイド](../../assessment/practice/protection-reviewer-guide.md)、[専用受入確認](../../tests/coach-behavior/acceptance-protection.md)を同じコミットで参照します。

実行者は本人、確認担当者が支援と原回答を確認します。環境は会社管理PCのブラウザ・会社アカウントのGemini通常チャット。実行時点は[環境事前確認](../../tests/coach-behavior/runtime-preflight.md)と利用目的・非公開保存先の承認後です。先行するW-A1→W-B1の受入を省略しません。

[導入ガイド](../../docs/getting-started.md)に従いmainからコミットを固定し、開始文のGitHub Raw本文を新しい通常チャットへ全文貼付けします。ファイルの完全な参照先は[GitHubの開始文](https://github.com/itdojp/workplace-competency-framework/blob/main/learning/W-H1/start.txt)から取得し、記録にはmain URLではなく固定コミットURLを使います。対象PRは通常該当なし。未マージ版だけ、実在するPR番号・head branchを記録します。

Q1→Q2→Q3の初回答、支援、修正を残し、希望する場合に別場面X01へ進みます。20分は初回の目安で、超過・支援利用を自動減点しません。記録後に終了・再開できます。Gems/Skills登録、検索、実際の送信・登録・共有変更は使いません。

## 観察と記録
[学習記録](../../templates/learning-record.md)へ教材ID・版・コミット・固定URL、設問、原回答、支援、修正理由、既見、未実施を記録します。AI案を本人が会話と照合し、承認された非公開先へ保存します。AIが保存したとする発言を保存証拠にしません。

確認用の[DX05](../../assessment/practice/DX05.md)は別資料です。D-H1・D-H2の単独診断は未制作で、同一実施の回答を独立した2場面へ数えません。公開教材の既見を確認し、同日転移と別日の未使用課題による確認を分けます。必要な再確認の対象と日程は人間が決めます。

## 変更範囲・中止・復旧
変更対象は新規のチャットと非公開回答記録だけ。公開原資料、既存回答、正式評価、会社権限、Google設定は変更禁止です。教材の判定上の「実施可」は実操作の許可ではありません。

条件改変、解答の先出し、架空の保存・送信報告、実データ混入時は試行を止め、原回答を保持して担当者へ連絡します。公開する不具合報告は架空再現だけとします。教材訂正は[GitHubのPR](../../CONTRIBUTING.md)で行い、マージ後の誤改訂は履歴を残した修復PRで戻します。承認版と利用条件を再確認して新規試行を行い、既存回答を書き換えません。

固定教材は恒久資産の試作、通常チャット貼付けは暫定実行方式です。期待結果は根拠付きの判断と再確認方法を残すことであり、能力認定や採用合否の自動決定ではありません。
