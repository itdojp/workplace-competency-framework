## 実行条件と手順

実行者は学習者本人。会社が許可した会社管理PCのブラウザ・会社Google Workspaceアカウント・Gemini通常チャットを使います。教材確認担当者は[環境事前確認](../../tests/coach-behavior/runtime-preflight.md)を行い、[導入ガイド](../../docs/getting-started.md)に従います。W-A1→W-B1の先行受入と既存教材の計画は維持します。掲載・マージは配付許可ではありません。

通常の参照開始点は`main`、使用対象は選択したコミットの[learning/W-C2/start.txt](start.txt)です。GitHubのファイル画面でコミット固定リンクを取得し、全文をRaw表示からコピーして新しい通常チャットへ貼り付けます。PC内の保存場所やGit操作は不要。対象PRは通常「該当なし」、未マージ版を使う場合のみ実在するPR番号・head branch名を記録します。参照コミットと固定URLはどちらも記録します。

初期資料→Q1→Q2の初回答・支援・修正→固定の変更資料R03→Q3→Q4→任意のX01の順で進みます。変更前の初回答は消しません。教材内の時刻は実時計に同期せず、R03は本人が実行した結果とは扱いません。待ち時間に他作業を行うことと、本人が二つの作業を同時実行することを区別します。

期待する成果は、制約を満たす計画・根拠・条件変更後の判断・相談案と修正理由です。学習者はメモ、電卓、表計算、読み上げなどを利用できます。提示形式の支援と内容上のヒントを区別し、利用した支援を記録します。変更後に必要な相談をすることを自律性不足とはしません。

変更対象は新規の試行チャットと承認済みの非公開学習記録だけです。実メールの送信、業務記録の更新、カレンダー作成、個人情報入力、会社設定変更、公開教材や確定評価の上書きは禁止です。

## 中断・エラー・復旧

「記録」「中断」「終了」でAIの記録案を得て、原回答・支援・提示済み資料と照合します。自動保存はありません。保存先・閲覧者は会社が事前指定し、実際の回答や人事評価を公開Issueへ貼りません。

計算や順序に不整合があれば確認ガイドと照合し、教材の許容条件に合う別解を否定しないよう確認します。AIによる条件改変、追加資料の先出し、架空の相談・保存報告があれば試行を止め、該当箇所を非公開で記録します。失われた初回答を推測復元せず、やり直しは新規試行として残します。

教材の訂正は[GitHub上の変更手順](../../CONTRIBUTING.md)に従ってPRで行います。マージ後の通常の誤りは履歴の変更前コミットを参照して修復PRで戻します。実機適合・会社の承認が確認できない版を全社員へ配付しません。誤公開は[公開方針](../../docs/publication-policy.md)と[SECURITY.md](../../SECURITY.md)に従います。今回の恒久教材制作と、後から行う実機確認・用途承認は別工程です。

`materials.md`と開始文の固定資料区画は全文同一に保ち、変更時は両方・版・確認ガイド・台帳の固定参照を同じPRで確認します。開始文を読むだけで全場面を閲覧できるため、未見性を技術的に保証しません。DX04は独立した未使用資料で実施し、既見なら明示します。
