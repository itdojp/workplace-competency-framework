## 練習と記録

Q1〜Q4→共通確認観点→別場面XQ1・XQ2の順。初回答、支援、修正を残す。20分で全問を要求せず、中断・継続を記録する。電卓・表計算等の通常支援を認め、速さだけで評価しない。

[学習記録](../../templates/learning-record.md)はW-A1/W-B1向け設問数を流用せず、非公開コピーでワークIDをW-A3、教材版を0.1-draftとし、Q1〜Q4・XQ1・XQ2の行を設ける。共通CSVを使う場合は各設問IDを記録する。参照コミット・固定URL、実施日、モデル表示を人間が確認する。原回答はAIの要約で置換しない。

[DX02](../../assessment/practice/DX02.md)は初回答を生成AIなしで確認する別の公開練習。今回の自己練習結果をそのまま採用本番の点数にしない。遅延確認には未使用の資料と支援条件を別に決める。公開問題を見た場合は既見として扱い、一般的な学習転移や問題難度の同等性を断定しない。

## 停止・復旧

計算根拠の不一致、原資料改変、回答先出し、架空の保存報告、実データ要求は試行を止める。元資料・初回答を保持し、人間が確認ガイドと再計算で照合する。モデルの説明だけで適合へ変更しない。

文書の誤りは[変更手順](../../CONTRIBUTING.md)に従ってPRで訂正し、マージ済みの通常の誤りは履歴から復元PRで戻す。チャットで固定資料が失われた場合は推測せず、新規試行または確認済み記録からの継続とする。承認済み実機適合版がなければ全社員配付に進めない。

一時方式は通常チャットへの全文貼付け。恒久方針は教材・AI指導・個人記録・実行基盤の分離。今回Google保存・通知・採点・Gems/Skills登録は行わない。
