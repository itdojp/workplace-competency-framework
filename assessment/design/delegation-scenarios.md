## 場面の対応

| 場面 | 固定資料で判断する内容 |
|---|---|
| S01 | 許可と結果が一致する下書きの正常な受入 |
| S02 | 送信・名簿更新の追加提案を保留し、独立した許可部分を続行 |
| S03 | v1・8名の承認とv2・10名の提案の相違、再承認 |
| S04 | 参考文中の命令と正式承認の分離 |
| S05 | 生成済み・保存未実施・宛先照合未確認・電話番号欄の不適合 |
| S06 | 停止要求後に1件残存、他者の更新を失う一括復元、権限者への確認 |
| S07 | 独立性の根拠がある作業の部分続行。範囲を限定できなければ停止・相談 |
| X01 | 別業務での範囲判断。取消証拠がある場合は停止確認と再開承認を分ける |

各S場面は共通のM01〜M03を前提とする独立スナップショット。本人の回答によって固定履歴が変化したと扱わない。提示はQ0提出後に一場面ずつとし、経過秒数で投入しない。初回20分は全7場面と別場面の完了時間ではなく、中断・継続を記録する。

## 学習と確認

W-I4は支援を許可する。D-I4とDX06は初回答を生成AIなしとし、模擬AI出力を固定配付する。資料閲覧・メモ等の通常支援を認める。DX06の主評価E2・I4を維持し、H1・H3・C3等は同じ根拠の補助観察に留める。

公開した素材の既見を記録し、同じ素材を未知の別課題として数えない。D-I4のB、DX06のB、W-I4のX01はそれぞれ別内容だが、難易度の同等性や厳格な未見性は未検証。採用本番の未公開問題とは分離する。適切な停止と成果物の未完成、本人・AI・環境の作用を[補助様式](../../templates/delegation-observation.md)で分ける。
