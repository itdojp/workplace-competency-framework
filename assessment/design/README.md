## 更新時の確認

教材を変更する場合は、対象ID・教材版・参照コミット・参照先本文を確認し、必要なCSVのURLと本表の固定参照先を同じPRで更新します。リンク先のコミットが実在し、公開対象の教材を含むことを確認してください。

CSVの見出し・列順を維持し、全行が見出しと同じ列数かCSVパーサーで確認します。セル内にASCIIカンマを入れる場合はそのセルを二重引用符で囲みます。隣り合う別列の区切りカンマを、セル内のカンマと誤認して削除・引用しません。単純な文字列分割ではなく、引用符を扱えるパーサーで照合します。

リンクや版が不一致なら利用を保留し、[導入ガイド](../../docs/getting-started.md)の方法で使用版を確認します。文書修正は[変更手順](../../CONTRIBUTING.md)に従ってPRで行い、誤りがマージ済みならGitHubの履歴から変更前を確認して修復PRで戻します。教材本文の修正、実機受入、個人記録の更新は、この案内の修正とは別の作業です。
