# W-A1／W-B1 評価者用確認基準
版：0.2-draft／用途：育成試作の受入と人間による観察
このファイルはAIへの入力必須資料ではない。採用試験の非公開採点キーでもない。全員分の評価や個人情報を追記して公開配付しない。

## 1. 共通原則
原資料に明記された事実と、合理的だが未確定の提案を分ける。未確認の確認先を自信をもって断定しないことを評価する。記述が正確であれば、形式・言い回しの違いを理由に不正解としない。
既存の能力水準0～3を、この一回の練習だけで確定しない。未回答は未確認であり自動的に0ではない。支援ありの成果と支援前の成果を混同しない。

## 2. W-A1主課題の確認
| 設問 | 原資料で確認できる内容 | 注意 |
|---|---|---|
| Q1 | 研修案内の下書き。実送信・会議作成はしない。[1] | 作成と実行を混同しない |
| Q2 | 在籍社員12名。外部参加者・入社予定者2名は対象外。[2] | 12+2=14名を対象としない |
| Q3 | 開催2026年10月9日10時、オンライン45分。下書き提出2026年10月6日15時まで、研修責任者へ、承認を得る。[3][4] | 開催日と提出期限を区別する |
| Q4 | 氏名・所属のみ。電話番号・健康情報は収集しない。[5] | 明記されない個人情報を追加しない |
| Q5 | 会議URL、参加希望の回答期限が未確定。[3][6] | [6]の担当者の氏名は未指定。[3]のURL確認先の役割も明記なし。研修責任者へ相談する案は許容するが、原資料の確定事項とはしない |
| Q6 | 前年の対面60分、電話番号必須、2025年10月1日締切を適用しない。[7] | 参考資料を優先しない |

未確定事項があるため何も着手できない、という回答を唯一の正解にしない。下書きに未確定と確認事項を残して作れる部分は進められる。送信・会議作成は範囲外。

## 3. W-B1主課題の確認
完成案内文の巧みさではなく、要件と受入条件の整理を見る。
- 成果物と範囲を、下書き作成・提出・承認と、実送信や会議作成の非対象に分けている。
- 対象、日時、期限、収集項目、前年との差が原資料と整合している。
- 未確定のURLと回答期限を作らず、未確定表示と確認を含めている。
- 提出可能性の確認項目に、条件反映、対象外、禁止事項、未確定表示、誤記・前年残存の確認を含める。原資料にない文体や字数制限を勝手に必須化しない。
- 資料を確認する→確定事項と未確定を分ける→下書き→照合→期限までに研修責任者へ提出し承認を得る、という合理的な順序がある。全く同じ表現・順序だけを正解にしない。
- 『必要な人が研修内容を理解できる案内』など資料から推定した目的は、提案・解釈と区別できていれば許容する。依頼に書かれていない事業効果を事実にしない。

## 4. 別場面の確認
W-A1：下書き、研修A8名、研修B3名除外、申請11/4 17時、受取11/6、返却期限未定・管理担当確認、社員ID・機器番号のみ、自宅住所なし、承認前配布なし、前年条件を採用しない。
W-B1：下書き、会議室A利用部署代表4名、Bのみの部署代表3名除外、11/10 12時総務責任者へ提出・承認、回答期限と配布方法が未定、部署名と利用回数、不便点は任意、個人評価・健康情報は収集しない、前年の全社員/旧締切/個人評価必須を採用しない。
別場面で使った確認方法を、本人が説明できたかを残す。AIが代理で説明したことを本人の理解の証拠にしない。

## 5. 判定方法
各観点は『確認できた』『支援後に確認できた』『追加確認が必要』『未実施』で記録する。順位付けや総合点による合否は出さない。
同じ初回答をW-A1・W-B1双方で独立した証拠として水増ししない。実務への転移は、別の日の未公開課題または権限確認済みの実務観察で人間が確認する。
