# 根拠評価・不確実性：人間の確認ガイド

版：0.1-draft。対象は[W-A4](../../learning/W-A4/README.md)、[W-D1](../../learning/W-D1/README.md)、[DX03](DX03.md)。公開練習の解説です。教材制作時の論理照合と、複数人間評価者による確認・学習効果の検証を区別します。後者は未実施です。

## 共通の判断規則

主張を分け、原資料が何を支持・反証し、何を記録していないかを確認します。「根拠で確認」は架空資料内で確認できる意味で、現実の規程を保証しません。資料束にない引用は未確認であり、不存在・捏造と断定しません。反証する記録がある主張は未確認へ弱めません。仮説は可能性として述べるもので、原因が確定したこととは別です。

適用条件と対象が一致する正式資料を確認します。新しいから常に正しい、正式だから対象外にも適用できる、AIが二つ一致したから独立根拠が増えた、という判断は採用しません。実施者は外部検索をせず、追加確認の計画まで作ります。

D1は分類の正答だけで認定しません。本人が説明できるとした内容を資料と照合し、分からない理由と必要な確認が具体的か、追加資料で判断を適切に更新したかを見ます。確信の強弱・自己申告・文章量・相談回数を得点化しません。支援と初回答を分け、一課題から能力全体や採否を確定しません。[根拠の帰属](evidence-attribution.md)と[評価原則](../../framework/assessment-principles.md)を維持します。

## W-A4

| 対象 | 根拠と許容する判断 |
|---|---|
| Q1 | A4-R00の受付11月18日はROOM-v1の範囲内。利用12月6日を理由にROOM-v2へ切り替えない。通常上限2時間 |
| Q2・A4-C1 | 反証あり。A4-R01/R02の受付基準・遡及なしに反する |
| Q2・A4-C2 | 未確認。A4-R03は受付票で承認の有無を記録しない。「承認がない」「拒否済み」とは断定できない |
| Q2・A4-C3 | 根拠で確認。予約10:00〜12:00は2時間で上限内。延長の承認とは別 |
| Q2・A4-C4 | 反証あり。A4-R05はAI-B→AI-A→FAQという同じ由来を明示。原資料が二つ確認されたことにはならない |
| Q3/Q4 | RQ41の10:00〜13:00を対象にした施設管理責任者の承認記録・有効条件を確認する。確認待ちでも予約済み時間と延長確認中を分けた下書きは作れる。送信・照会を実行したとは記録しない |
| X01 | A4-XR02が研修Bの旧期限を明示的に置換するため12月5日。最新の研修Cの12月8日は対象外。旧資料を常に選ぶ暗記も不可 |

FAQに情報があるという事実と、その情報がRQ41へ適用できることは別です。合理的な確認質問・部分的な下書きを認めます。原資料にない承認方法や追加条件を必須解答にしません。

## W-D1

| 主張 | 初期資料D1-R00〜R03のみ | D1-R04提供後 |
|---|---|---|
| D1-C1 | 保存成功はD1-R01で確認 | 変更なし |
| D1-C2 | 送信は記録対象外なので未確認 | TX71で10:05の送信成功を確認。ただし配達・閲覧は未確認 |
| D1-C3 | 必須の利用目的が空欄という反証あり | 変更なし |
| D1-C4 | 承認待ちはD1-R01で確認 | 変更なし。原因の説明が追加される |
| D1-C5 | 欠勤原因説は未検証の仮説。断定された原因としては未確認 | NOTE73により欠勤原因説は反証され、重複申請の照合保留が確認される |

Q1でD1-C5を「仮説」または「原因は未確認」とし、メモの推測性を説明する回答はいずれも許容します。Q2ではS71の送信履歴、S73の保留理由を管理・承認担当へ確認する計画を認めます。勤務情報を広く収集する必要はなく、業務上の保留理由を確認すれば足ります。

Q3/Q4では初期資料での適切な未確認を後知恵で誤答にせず、追加資料後の更新を区別します。最初の断定が誤っていた場合も原回答を保持し、修正した根拠を観察します。追加資料前にAIがTX71やNOTE73を解答・ヒントへ使った場合はコーチの不適合を別記し、初期判断の独立性を扱い直します。

X01は、点検合格・予約確定がD1-XR01/R02で確認できます。予約不明というAIの主張は反証されます。引渡しは記録対象外のため未確認であり、「引渡し済み」「未引渡し」とも断定しません。引渡し担当の記録確認を次の行動にできます。

## DX03

| フォーム・観点 | 根拠と判断 |
|---|---|
| A・方法 | 開催1月18日はSUB-v2の1月15日以降に該当。通常は申請フォーム。1月11日更新メモは新しくても旧手順の二次資料 |
| A・A-C1〜C4 | C1反証あり、C2開催日はR00で確認、C3未確認、C4反証あり。同じAIに出典が不足していてもC2の内容自体は資料束で確認できる |
| A・不足と限界 | FAQ-17は本文・発行者・適用対象が未確認。不存在を断定せず、研31の個別承認を責任者へ確認する。通常の方法と例外の確認待ちを分離 |
| B・方法 | 受付2月12日はLOAN-v1の対象。通常上限5日。利用2月20日や新FAQを理由に10日へ変更しない |
| B・B-C1〜C4 | C1反証あり、C2受付日はR00で確認、C3はEX-L52の不承認で反証あり、C4反証あり |
| B・不足と限界 | 既存資料には明確な不承認があるため、現在の例外状態を漠然と未確認にしない。後日承認があるという主張には、L52・期間・責任者・旧判断の置換を確認する計画を示す |

A4は情報源と適用条件の選択、D1は本人の説明可能範囲と確認計画として観察します。同一回答の二つの観点を、独立した二回の実績には数えません。A/Bは構造を揃えた公開試作ですが、難度が同等であるとは未検証です。

## 評価者の判断合わせに使う架空回答

以下は制作した例で、社員の回答ではありません。実際の評価者の採点結果ではありません。

| ID | 架空回答 | 確認する相違 |
|---|---|---|
| S-K01 | W-A4：FAQが最も新しいので3時間で確定する | 発行の新しさと適用条件を混同。反証のある断定を指摘できるか |
| S-K02 | W-A4：承認記録を見ていないので延長は拒否された | 未確認と不承認を混同。通常予約は案内できる点も見る |
| S-K03 | W-D1初期：S71保存は確認、送信はこの表では分からない。送信履歴を確認する | 具体的で適切な限界認識を、消極性と誤評価しない |
| S-K04 | W-D1追加後：最初から送信済みと分かっていたことに記録を書き換える | 原回答保持と資料提供時点を区別する |
| S-K05 | DX03-A：引用FAQ-17は本文不明だが、開催日1月18日はR00で確認できる | 出典に欠陥がある回答を全否定しない |
| S-K06 | DX03-B：不承認の記録があるが、全部未確認として回答を止める | 根拠で分かることまで未確認にしない。合理的な追加確認は許容 |

評価担当者2名が独立に、判断・根拠・不足・支援条件を非公開先へ記録してから比較します。相違は例の不足、資料の曖昧さ、基準の解釈に分けて修正します。AI一者の点検を複数評価者の校正と呼びません。

| 校正記録の項目 | 状態 |
|---|---|
| 使用コミット・教材版・対象例 | 未記入 |
| 評価者A／Bの独立確認・根拠 | 未実施 |
| 不一致・修正理由・再確認 | 未実施 |
| 用途・支援条件・残課題の承認 | 未実施 |

実施者・内部URL・評価を公開ファイルへ追記しません。記録様式の設計と人間による実施は別です。不整合時は判断を保留し、元の回答を残して[修復PR](../../CONTRIBUTING.md)で教材を訂正します。学習効果や採用妥当性は別工程で検証します。
