# スプレッドシート用の空の記録様式

このディレクトリのCSVはUTF-8のヘッダーのみです。個人情報もサンプルの個人評価も含みません。CSVをコピーしただけで数式・入力規則・集計が実装されるわけではありません。既存v0.1の数式付きXLSXを置換するものではありません。

実行者：会社の評価管理者。実行環境：会社Google Workspaceのスプレッドシート。実行時点：保存先、共有者、利用目的、保存期間を承認した後。対象branch/PR：Google上の運用は該当なし。変更対象：新規の制限付き管理ファイル。変更禁止：公開リポジトリへの個人記録の保存、既存ファイルの上書き。

CSVを用途別の新規ファイルへ取り込みます。学習記録は本人と確認者、評価・証拠・育成計画は必要な担当者だけに共有します。非表示シートや編集保護を閲覧権限の代わりにしません。個人の実データ入力前に共有範囲と列名を確認し、不一致なら入力を停止して空テンプレートから新規作成します。誤共有時は共有解除と会社の事故対応を優先します。

未評価はU、対象外はNA、能力水準は0～3。AIコメント案と人間の確定評価を別列にし、自己評価やAI提案を直接確定値にしません。証拠IDと評価IDは固定し、再評価は新しい行で保存します。実行日時・モデル名は本人が確認し、AIの推定値を使用しません。

能力辞書の変更提案はGitHubのPRで承認し、承認済みの版をGoogle側へ反映します。個人データの自動同期はありません。Google保存先URLは本公開リポジトリに記載しません。
