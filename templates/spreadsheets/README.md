# スプレッドシート用の空の記録様式

公開しているCSVはUTF-8のヘッダーのみです。GitHubのファイル表示から列名と列順を確認できます。個人情報もサンプルの個人評価も含みません。PCへの保存、リポジトリ外のブック、過去の配布資料は前提にしません。

| 用途 | リポジトリルート相対パス | 入力後の共有範囲 |
|---|---|---|
| 学習記録 | [templates/spreadsheets/learning-records.csv](learning-records.csv) | 本人と確認担当者 |
| 根拠記録 | [templates/spreadsheets/evidence.csv](evidence.csv) | 必要な評価担当者 |
| 能力評価 | [templates/spreadsheets/evaluations.csv](evaluations.csv) | 必要な評価担当者 |
| 育成計画 | [templates/spreadsheets/development-plans.csv](development-plans.csv) | 必要な担当者 |

**数式、入力規則、自動集計を備えたブックは本リポジトリでは未提供です。** CSVや列名をコピーしただけで、それらが実装されるわけではありません。

## 参照と利用

実行者は会社の評価管理者です。参照環境はGitHubのブラウザ画面、運用環境は会社が承認したGoogleスプレッドシートです。参照開始点は`main`とし、[導入ガイド](../../docs/getting-started.md)の方法でコミットを固定します。Google上の記録作業に対象branch・PRはありません。テンプレート自体の改訂は`main`に対する別PRで行います。

実行時点は、非公開保存先、共有者、利用目的、保存期間を承認した後です。変更対象は新規の制限付き管理ファイルだけで、GitHubの空テンプレートや既存の運用ファイルを個人記録で上書きしません。

GitHubに表示された列名を列順どおりに、用途別の新規スプレッドシートへ設定します。Raw表示からヘッダーをコピーすることもできます。カンマ区切りの1行を1セルに貼り付けただけでは、列設定は完了していません。公開CSVと列名・列数・順序を照合し、必要な入力確認を管理者が設計してから、個人の実データを入力します。

期待結果は、参照したコミットと列定義が分かり、用途ごとに閲覧者を限定できることです。非表示シートや編集保護を閲覧権限の代わりにしません。列や共有範囲が一致しなければ入力を止め、同じコミットのCSVから再確認します。復旧のために作り直す場合も新規の非公開ファイルとし、既存記録を消しません。誤共有時は共有解除と会社の事故対応を優先します。

## 評価と更新

未評価はU、対象外はNA、能力水準は0～3です。AIコメント案と人間の確定評価を分け、自己評価やAI提案を直接確定値にしません。証拠IDと評価IDは固定し、再評価は新しい行で保存します。実行日時・モデル名は本人が確認し、AIの推定値を使用しません。

[能力辞書](../../framework/competencies.csv)の変更はPRで承認し、承認済みの版をGoogle側へ反映します。個人データの自動同期はありません。記入済みのファイル、内部保存先URL、共有者一覧は[公開方針](../../docs/publication-policy.md)に従ってGitHubへ登録しません。
