# スプレッドシートの記録様式

## 数式付きの構築用原本

[v0.1の導入手順](v0.1/README.md)に、タブごとのTSV、数式の種行、入力規則、架空ケースの検証を追加した。診断・根拠・育成・学習・再評価をIDで関連付ける。Googleへの自動作成・自動保存はなく、会社Workspaceの受入は未実施。原本を貼るだけで入力規則や全行の数式展開が完了するわけではない。

| 用途 | 既存の互換列定義 | v0.1の構築原本 |
|---|---|---|
| 学習記録（本人ごとに別ファイル） | [learning-records.csv](learning-records.csv) | [learning.tsv](v0.1/learning.tsv) |
| 根拠記録（管理者） | [evidence.csv](evidence.csv) | [evidence.tsv](v0.1/evidence.tsv) |
| 能力評価（管理者） | [evaluations.csv](evaluations.csv) | [evaluations.tsv](v0.1/evaluations.tsv) |
| 育成計画（管理者） | [development-plans.csv](development-plans.csv) | [plans.tsv](v0.1/plans.tsv) |

既存4CSVはUTF-8ヘッダーだけの状態と列順を保持する。v0.1では既存列を左側へそのまま残し、必要な補助入力・検査列を右へ加える。別ファイルの本人・管理者間で無承認の自動共有・同期を行わない。公開するのは空原本と架空の検証資料だけ。

## 参照版・旧記録を保持する

各記録行の参照コミットは、実際に使用した既存CSV列定義・能力定義・教材の40桁SHAを固定値で記入する。参照固定URLは同じSHAの該当CSVを開くGitHub URL。branch名、タグ、省略SHA、最新mainへ追従する数式を代わりに使わない。取得した追加数式テンプレートの固定URL・版も運用ファイルの非公開管理メモへ残す。

担当者がURLの実在、SHAの一致、列順、使用教材版を確認する。数式は書式・照合状態の検査を補助するだけで、元の回答・承認の真実性を証明しない。未確認の行は確定を止め、推測で最新のSHAを補わない。Uは未評価、NAは承認された対象外、0は明示的な能力水準であり、空欄を0にしない。

再実施・再評価は新しい行・評価IDで記録し、過去の行を上書きしない。別評価へ過去の根拠を使う場合は、根拠の採取時の版を残してリンクで関連付ける。追加数式で移行前の記録を自動的に確定評価へ変えない。

旧様式の末尾に参照2列がない場合は、非公開の作業コピーで末尾へ追加し、元の列名・順序・ID・値を保持する。参照版を特定できない行は「未確認」のままにする。v0.1へ移す際も、入力列のみを値で移し、v0.1の原本から検査列を作成する。要求ID・前回評価ID・リンクを原資料で確認できる範囲だけ補記する。

## 実行・共有・復旧

実行者は会社の評価管理者。環境はGitHubの閲覧画面と会社承認済みのGoogleスプレッドシート。実行時点はアカウント・保存場所・閲覧者・目的・保存期間の承認後。[導入ガイド](../../docs/getting-started.md)に従いmainからコミットを固定する。未マージ版だけ実在PR・head branchを記録し、Google側の入力作業はPR対象外とする。

変更対象は新規の制限付き運用コピーだけ。公開原本、既存の個人記録、確定評価、会社の設定・権限・課金は変更しない。非表示や編集保護を閲覧制限として使わない。個人の回答・AI会話・評価・保存先URL・共有者一覧は[公開方針](../../docs/publication-policy.md)に従い公開GitHubへ登録しない。

期待結果は、原回答・支援・根拠・使用版と再評価を追えること。AIコメントは案であり、人間の値を自動確定しない。[受入確認](../../tests/spreadsheets/acceptance.md)のGoogle条件が未確認なら試行を越えた利用を保留する。不一致・式破損・誤共有は入力を止め、新規非公開コピーで旧記録を保持して復旧する。公開原本の訂正は[PR](../../CONTRIBUTING.md)、通常の誤改訂は修復PRで戻し、履歴を書き換えない。

教材・定義の正本はGitHub、個人記録の正本は会社Workspace。Apps Script、API、Gems/Skills、外部連携や自動人事判定はこの追加に含めない。
