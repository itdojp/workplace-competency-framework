# 委任・監督課題の観察補助様式

空様式。I4・H1・H3・C3等で必要な場面だけ使用し、全36能力やW-A1/W-B1に一律適用しない。
[記入原則と架空例](../assessment/practice/evidence-attribution.md)を参照し、会社が承認した非公開先へ項目をコピーする。実回答・内部URL・識別情報を公開GitHubへ書き込まない。

## 実施・参照情報

| 項目 | 記入欄 |
|---|---|
| 補助記録ID／既存の根拠ID／場面ID | 未記入 |
| 課題ID／教材版／主評価能力／補助観察能力 | 未記入 |
| 実行者／確認担当者／実施日 | 未記入 |
| 模擬課題／実務観察と、実行環境・支援条件 | 未記入 |
| 参照コミット／本様式・使用資料のGitHub固定URL | 未記入 |
| 未マージ版を使う場合のPR・branch | mainにマージ済みの版を使う場合は「該当なし」。未マージ版を使う場合のみ、実在するPR番号とhead branch名を記入する。 |
| 非公開保存先・閲覧者・保存期間の確認 | 未確認 |

## 結果を分けて記録する

| 観点 | 観察結果と根拠 |
|---|---|
| 成果物の完成・未完成 | 未記入 |
| 制約遵守・不適合・未確認 | 未記入 |
| 続行／部分保留／停止／相談の選択と理由 | 未記入 |
| 実施済み／未実施／未確認の操作・結果 | 未記入 |
| 停止要求の有無・根拠／停止確認の根拠 | 未記入 |
| 残存処理・残存リスク・復旧や再開の条件と承認 | 未記入 |

AIが「停止した」と述べただけで停止確認済みとしない。根拠のない状態は未確認、適用しない欄は理由付き対象外とする。状態と本人の能力水準は別である。

## 照合・訂正

| 項目 | 記入欄 |
|---|---|
| 初回答の参照／支援内容／修正回答の参照 | 未記入 |
| 誰がAI記録案を何と照合したか／確認日 | 未記入 |
| 不一致・訂正理由・訂正後の記述（原回答は保持） | 未記入 |
| 未確認事項／追加確認／同じ素材を既に見たか | 未記入 |

実行時点は保存・共有条件の承認後。変更対象は新規の非公開記録だけ。本人の原回答、確定評価、公開の空様式は上書きしない。期待結果は本人・AI・環境の作用を区別した証拠であり、合計点ではない。

不一致なら確定を止め、確認できる根拠だけを保持する。訂正は元記録を残して非公開先で行う。失われた記録は推測復元しない。[公開方針](../docs/publication-policy.md)と[参照版の保持](spreadsheets/README.md)に従う。
