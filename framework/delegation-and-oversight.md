# 委任・監督の行動基準（補足案）

状態：設計案・未検証。関連：[Issue #3](https://github.com/itdojp/workplace-competency-framework/issues/3)。
[能力辞書](competencies.csv)と[行動基準CSV](behavioral-anchors.csv)を補足する。新規能力ID、重複した総合点、全社員共通の新しい要求水準は追加しない。

## 能力・許可・制御を分ける

本人の能力は「条件を判断し、根拠を確認し、権限内で介入できること」、許可は「今回どの対象に何をしてよいか」、制御は「環境が何を許し、阻止し、観測できるか」である。高い能力水準は広い実行権限を意味しない。

人への分担、外注、RPA、AIのいずれにも適用する。一般利用者には、制御の有無と限界を確認し、不明なら相談する行動を求める。アクセス制限や監視機構の実装・承認責任は組織と管理者にあり、利用者の注意力で代替しない。

## 観察の四段階と既存能力

| 段階 | 観察する行動 | 主な対応能力 |
|---|---|---|
| 委任前の条件定義 | 対象ID・版・宛先、許可／禁止操作、承認者、受入条件、再委任の可否を区別する | B1・I4 |
| 制御と根拠の確認 | 操作可能と許可済みを分ける。承認対象と現対象を照合し、観測・停止の方法を確認する | H1・H2・I2 |
| 作業中の判断・介入 | 変更や不一致の影響を特定し、続行・部分保留・停止・相談を選ぶ。停止依頼と停止確認を分ける | H3・C2・D4・I4 |
| 受入・引継ぎ | 許可の記録、実行の記録、結果の証拠を照合し、実施済み・未実施・未確認を区別する | C3・C4・H4 |

D3・G2・G3では、人間が確認・介入できる量と、手戻りを含む負担を扱う。確認能力を超える並行数なら委任範囲を縮小し、期限や分担を相談する。生成件数の増加だけを成果としない。

同じ回答を複数の独立した能力証拠に水増ししない。主評価能力を事前に決め、他の能力は同じ根拠に対する補助観察とする。

## I4の水準を区別する観察例

[共通水準](proficiency-levels.md)の意味は変更しない。以下は評価者が職務例へ具体化するための補足であり、合否の自動判定表ではない。

| 水準 | 観察例 |
|---|---|
| U／NA | 証拠不足はU。対象職務・課題に適用しない場合は理由付きでNA。いずれも0へ置換しない |
| 0：未到達 | 課題条件と支援を確認しても、操作可能を許可済みと扱う、承認対象の相違を解消せず実行を指示する等の不適合が残る。未完成だけでは0としない |
| 1：支援下 | 提供された対象表・権限表・確認手順と支援を使い、任せる範囲、確認待ち、停止・相談先を整理する |
| 2：定型自律 | 既知の業務で対象・承認・検証・停止手段を確認する。不一致を保留・相談し、受入根拠と未確認を残す |
| 3：非定型自律 | 条件変更、古い承認、矛盾する証拠、監視不能な範囲を識別する。権限内で分担・範囲を再設計するか、決定権者へ判断を求める |

## 職種をまたぐ具体例

| 場面 | 適切な行動 | 誤った結論 |
|---|---|---|
| 総務：案内の下書きだけを依頼 | 送信と名簿更新は保留し、許可された下書きは続ける | 送信ボタンが使えるので送信してよい |
| 経理：承認後に集計対象期間が変わる | 変更範囲と金額への影響を示し、確定処理の再承認を求める | 以前の承認があるので新しい集計も確定できる |
| IT：変更案の版が差し替わる | 承認された版・対象との差を照合し、本番反映を保留する | テスト成功だけで本番反映の許可も得た |
| 共通：引継ぎ資料に「承認済み」とある | 正式な承認記録と承認者の権限を確認する | 引用文が今回の権限を付与する |
| 共通：停止依頼後も待ち行列が残る | 停止は未確認と報告し、権限を持つ担当へ残存処理の確認を求める | 停止を依頼したので、処理はすべて停止済み |
| 共通：復旧案が他者の更新を上書きする | 復旧範囲・競合を確認し、再開・復旧の承認を得る | 元に戻す操作はいつでも無承認でよい |

続行の根拠がある部分まで一律に止めることを正解にしない。一方、影響範囲を限定できない場合の全停止・相談は妥当になり得る。評価では選択そのものではなく、その時点の許可、観測可能な事実、判断理由を確認する。

## 適用と見直し

制度責任者・職務代表・評価者が、適用する職務、必要水準、支援条件を承認してから使用する。I4のP2・AI増分「大」・第1期、H3の第2期は維持する。I4で停止の基礎を説明することをH3全体の制作期変更と扱わない。

記録は[帰属の原則](../assessment/practice/evidence-attribution.md)と[委任観察の補助様式](../templates/delegation-observation.md)を使う。教材・環境が異なる結果を単純比較せず、指導不足・権限不足・道具の問題と本人の判断を分離する。改訂は[変更手順](../CONTRIBUTING.md)に従う。
