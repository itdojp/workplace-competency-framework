# 能力水準

| 値 | 定義 |
|---|---|
| U | 未評価・証拠不足。数値へ変換しない |
| NA | 職務上の対象外。判断理由を非公開の運用記録に残す |
| 0 | 当該課題と支援条件では必要な行動が確認できない |
| 1 | 具体的な指示と確認があれば実施できる |
| 2 | 定型状況で自律的に実施し、異常時に確認・相談できる |
| 3 | 非定型・条件変更でも適切に判断し、方法を調整できる |

空欄や未回答を0へ変換しません。人物全体の能力や性格を表す値ではありません。支援条件、課題、根拠、評価日、評価者を併記します。高い実務能力から指導能力・管理能力を推定しません。

P1/P2は重要度、AI増分は必要性の変化に関する設計判断、開発期は制作順序です。重要度と要求水準、開発順序を同一視しません。前提能力IDは学習設計の参考であり、採用上の機械的な足切り条件ではありません。
